### План работы

#### Чекпойнт 2. Разведочный анализ данных

- исследовать состав, классы и качество данных PlantVillage и PlantDoc
- найти ошибки, дубликаты и почти-дубликаты изображений
- проанализировать условия съемки
- сопоставить общие классы и визуализировать эмбеддинги с помощью UMAP или t-SNE
- подготовить воспроизводимое разбиение данных и сравнить качество модели на PlantVillage и PlantDoc

**Что сделали:** проверили классы, размеры и качество снимков, нашли повторы и
конфликты меток, сравнили фон и цвет, посмотрели аугментации и t-SNE признаков
ResNet18. Подготовили разбиение с `seed=42`.

Из 54 305 снимков PlantVillage и 2 572 PlantDoc осталось 54 236 и 2 479.
Для сравнения выбрали 23 общих класса. Модель пока не обучали.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/download_data.py
python scripts/execute_notebook.py
```


**Важно для следующих этапов:**

- Данные взяты у авторов: [PlantVillage](https://huggingface.co/datasets/mohanty/PlantVillage)
  и [PlantDoc](https://github.com/pratikkayal/PlantDoc-Dataset).
- PlantVillage разбит примерно на 70/15/15. Снимки одного листа и найденные
  повторы объединены в группы. PlantDoc train/test после очистки используются
  как `field_dev`/`field_test`; итоговый тест не используем для подбора настроек.
- Из рабочих списков исключены точные копии, почти-дубликаты
  (Хэмминг ≤ 6 и RGB ≤ 0.035) и группы с конфликтующими метками.
- Также пока предлагаем Macro-F1 по общим классам, метрику согласуем позже по чекпоинтам.
- Код обработки в `scripts/`, таблицы в `data/processed/`, графики
  и результаты в `reports/`. В Git сохраняем их, ноутбук и `splits/`.
  Исходные фото в `data/raw/`, веса, `.venv` и временные файлы исключены через `.gitignore`.
