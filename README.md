# Классификация изображений с Transfer Learning

</div>

### О проекте

Цель проекта — построить модель классификации изображений с использованием
transfer learning на предобученной нейронной сети.

### План работы

#### Чекпойнт 2. Разведочный анализ данных

- исследовать состав, классы и качество данных PlantVillage и PlantDoc
- найти ошибки, дубликаты и почти-дубликаты изображений
- проанализировать условия съемки
- сопоставить общие классы и визуализировать эмбеддинги с помощью UMAP или t-SNE
- подготовить воспроизводимое разбиение данных и сравнить качество модели на PlantVillage и PlantDoc

#### Чекпойнт 3. Первые модели и baseline

- согласовать основную и вспомогательные метрики
- обучить простую baseline-модель на PlantVillage
- зафиксировать результаты baseline для последующего сравнения

#### Чекпойнт 4. ML-сервис

- реализовать ML-сервис на FastAPI
- добавить загрузку модели, обработку входных данных и получение предсказания

#### Промежуточная защита

- подготовить презентацию о проделанной работе и планах на второй семестр

#### Чекпойнт 5. Улучшение модели

- проверить влияние разных аугментаций и замены фона на качество модели
- применить методы борьбы с дисбалансом классов
- сравнить несколько архитектур по качеству, размеру и скорости инференса
- определить, какие изменения сокращают разрыв между PlantVillage и PlantDoc

#### Чекпойнт 6. Малые данные и интерпретируемость

- исследовать более сильные архитектуры и способы их оптимизации
- провести few-shot-эксперименты с разным числом изображений на класс
- построить Grad-CAM для правильных и ошибочных предсказаний
- дополнить таблицу экспериментов метриками, гиперпараметрами и временем обучения

#### Чекпойнт 7. Финальные доработки

- настроить воспроизводимость экспериментов и логирование в MLflow
- переобучить и сохранить лучшую модель
- провести анализ ошибок и проверить устойчивость к искажениям изображений
- подготовить финальную документацию и демонстрацию проекта

#### Итоговая защита

- подготовить итоговую презентацию и продемонстрировать результаты проекта
